Entry for the [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) competition on make.fun.

`main.py` writes a single line (at most 200 characters) in which a robot vacuum explains why it missed a spot, to `/output/entry.txt`. No network, no input, deterministic.

Run it:

```sh
python3 main.py
```
